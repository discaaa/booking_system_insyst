# BookaRoom
A room booking web application built with React and Vite.

## Features
- Browse available rooms
- Select booking dates and time slots
- Enter customer details
- Review booking information
- View booking confirmation

## Tech Stack
- React
- Vite
- CSS
- JSON Server (for mock API data)

## Getting Started
Install dependencies:
```bash
npm install
```
Start the development server:
```bash
npm run dev
```
If using JSON Server, start it in a separate terminal with the appropriate command configured for `db.json`.
